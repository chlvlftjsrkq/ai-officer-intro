SETUP · 추가 준비

기존 녹취는 유지하고,
송신기와 PC 수신을 연결합니다.

기본 PC 설치에 아래 서버 설정을 추가합니다. Line-in 운영에는 이 서버 구성과 Npcap 설치가 필요하지 않습니다.

01 · 서버 준비

기존 미디어가 들어오는 NIC

기관 SERVER 반입본과 Npcap을 준비합니다. 이미 정상 작동 중인 Npcap은 재설치하지 않습니다. 원본 녹취 프로그램의 수신을 유지하며 음성을 복사합니다.

02 · 연결 설정

같은 키 · 수신 PC · 시각

서버와 PC가 같은 연결 키를 사용하도록 하고, 업무 PC의 IP·UDP 포트를 맞춥니다. 기본 수신 포트는 29000이며 방화벽과 두 장비의 날짜·시각을 확인합니다.

03 · 번호 로그

채널과 내선은 별개입니다

오늘의 SoluIP 일반 로그에서 번호와 통화 상태를 연동합니다. 녹취채널은 매 통화마다 달라질 수 있으므로 채널 번호를 직원 내선으로 고정하지 않습니다.

04 · PC 입력

녹취서버 입력과 나의 내선

PC 설정에서 녹취서버 수신을 켜고, 입력 방식을 녹취서버로 선택합니다. 나의 내선번호를 입력한 뒤 자동 녹음·STT를 켜고 새 시험 통화를 확인합니다.

번호·음성이 함께 확인될 때 시작지원되는 번호 로그와 내선·채널의 실제 음성이 맞아야 자동 시작합니다. 번호가 모호하거나 로그가 끊기면 다른 전화로 임의 전환하지 않습니다.
수신과 STT는 따로 확인서버 forwarded, PC 수신량, 선택 통화의 코덱과 STT 전송량을 확인합니다. 20채널을 모니터하되 한 PC의 자막·녹음은 확인된 한 통화를 처리합니다.
