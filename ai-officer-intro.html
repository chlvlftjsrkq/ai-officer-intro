04 이어지는 분석

한 번의 답변보다,
계속 이어지는 이해.

새 발언이 쌓이면 다음 분석에 반영합니다.
앞선 대화와 메모를 유지하며
필요한 자료를 찾고, 확인할 내용을 정리합니다.

  • ✓기관이 지정한 업무 자료에서 근거 검색
  • ✓후속 질문에도 같은 업무 맥락 유지
  • ✓진행 중 작업을 중복 실행하지 않는 분석 흐름
AI 업무 도우미이어지는 대화
추가된 통화 자막 · 예시“준비 자료를 확인한 뒤 다시 안내받고 싶습니다.”
01최신 통화·메모 확인맥락 확인
02관련 업무 자료 검색근거 찾기
03문서·쪽수와 확인 사항 정리직원 검토
04전화 메모 초안 갱신다음 발언 대기
처리 중 상태와 실제 도구 실행 결과를 구분해 보여줍니다.

분석 간격·발언 누적 조건을 설정합니다. 실제 처리 시간은 기관 API와 대기에 따라 달라집니다.

  • ✓직원의 수정과 메모 버전을 보호
  • ✓할 일·기한·확인 필요 사항 관리
  • ✓자막·대화·근거를 인계 문서로 저장

07 기관 환경에 맞게

08 설치와 시작

PC와 전화기를 연결하고,
한 번의 통화로 확인.

직원 PC에 앱을 설치하고
전화기 음성을 Line-in으로 연결합니다.
로그인 → 입력 장치 선택 → 입력 확인,
통화를 시작해 자막과 메모를 확인하세요.

PC 설치본 받기기본 설치 안내

공개 PC 설치본에는 인증정보가 없습니다.
호환 음성 어댑터와 기관 GOV API 설정을 준비합니다.
녹취서버가 있는 환경은 선택 구성 안내를 확인하세요.
