# AI-officer 소개 페이지

전화 음성을 실시간 자막으로 바꾸고, 이어지는 AI 분석·전화 메모·후속 업무로 연결하는 시스템의 소개입니다.

**[애니메이션 소개 열기](https://chlvlftjsrkq.github.io/ai-officer-intro/)**

- 자막 타이핑, AI 분석 단계, 메모 작성, 내선·채널 전환 예시
- 장면별 진행 막대·다시 보기·재생 및 정지
- PC·모바일 대응, 단일 HTML 오프라인 열기

[프로젝트 원본·설치 안내](https://gitlab.aigov.go.kr/pilddong/AI-officer)

이 저장소는 공개 소개 페이지 전용입니다. 소개 화면은 시연 예시이며 실제 통화, 기관 API 인증정보, 민원인 기록을 포함하지 않습니다. 실제 서비스는 기관 내부망의 설치 환경과 GOV API를 이용합니다.

## 갱신

원본 프로젝트의 `docs/intro/ai-officer-intro.html`을 `index.html`과 `ai-officer-intro.html`로 복사합니다. `.nojekyll`을 유지하고 `main` 브랜치의 루트 폴더를 GitHub Pages로 게시합니다.

페이지 구성 참고: [기후노트 소개](https://gonynim22.github.io/climate-note/climate-note-intro/climate-note-intro.html). 문구·장면·아이콘·코드는 AI-officer에 맞게 새로 구성했습니다.
